# ADRS - Age of Diplomacy Replacement Set

An AIRS fork for an MP game for an OpenTTD Diplomacy Mod game. 

## Attribution

ADRS is a fork of **AIRS** (Age of Industry Replacement Set) by andybiotic, itself
descended from **FIRS** by andythenorth, FooBar, planetmaker, Terkhen, Yexo and many
other contributors. 

Sprite art was pulled from the following projects, as well as from myself in a few places.
